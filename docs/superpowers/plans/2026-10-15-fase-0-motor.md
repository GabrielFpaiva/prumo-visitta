# Fase 0 — Motor 3D e spike na Vast.ai — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** construir o `engine/` (pipeline vídeo/fotos → COLMAP → gsplat → splat comprimido, empacotado em imagem Docker) e rodá-lo à mão na Vast.ai com 3 imóveis reais para decidir se o produto segue.

**Architecture:** pacote Python `visitta_engine` com um estágio por arquivo (entrada, quadros, SfM, treino, transporte), orquestrados por `pipeline.py`. Todo comando externo passa por um `Runner` e o COLMAP por um `ColmapBackend`, para os testes rodarem sem GPU. A instância recebe só a URL assinada de um manifesto JSON (contrato que a Fase 2 reaproveita), baixa as entradas, sobe as saídas por URL assinada e avisa por callback HMAC opcional.

**Tech Stack:** Python 3.11 (uv), pytest, OpenCV, Pillow + pillow-heif, pycolmap 4.2.1 (`pycolmap-cuda12` na imagem), gsplat v1.5.3 (`examples/simple_trainer.py`), torch 2.5.1 cu124, `@playcanvas/splat-transform` 3.10.1, ffmpeg, Docker (CUDA 12.4), GitHub Actions + GHCR, Cloudflare R2 (boto3) e Vast.ai CLI.

**Spec:** `docs/superpowers/specs/2026-10-15-prumo-visitta-design.md` (seções 7, 8, 10 e 12, Fase 0)

## Global Constraints

- Python ≥ 3.11; dependências gerenciadas por `uv` dentro de `engine/`.
- COLMAP **só via pycolmap 4.2.1** (sem binário `colmap`); na imagem, `pycolmap-cuda12==4.2.1`. Nunca instalar `pycolmap` e `pycolmap-cuda12` no mesmo ambiente.
- gsplat **v1.5.3** roda num venv separado (`/opt/train`), porque o `examples/requirements.txt` dele instala outro pacote chamado `pycolmap`.
- Imagem Docker **sem nenhum segredo**. **A chave da API da Vast nunca vai para o host**; quem destrói instância é sempre quem a criou.
- Códigos de erro (spec §8): `CAPTURE_TOO_FEW`, `CAPTURE_INSUFFICIENT`, `HOST_DOWNLOAD`, `HOST_CUDA`, `HOST_DISK`, `HOST_UPLOAD`, `ENGINE_ERROR`, mais `MANIFEST_INVALID`. Só `HOST_*` é repetível.
- Limiares: mínimo **40** imagens, máximo **300**; maior lado **1600 px**; `CAPTURE_INSUFFICIENT` quando o maior modelo registra **< 60%** das imagens.
- Identificadores e código em inglês; textos, docs e mensagens de erro para humanos em português.
- Commits em inglês, atômicos, **sem trailer `Co-Authored-By`**.
- Testes rodam com `cd engine && uv run pytest` sem GPU, sem rede externa e sem segredo.

## Review Focus

1. **Foto HEIC do iPhone** — o corretor sobe `.heic` direto da galeria; deve virar JPEG normal, não erro (teste na Task 3).
2. **Foto com rotação só no EXIF** — retrato salvo deitado com tag de orientação; deve chegar em pé ao COLMAP (teste na Task 3).
3. **Vídeo gravado em pé**, apesar do guia — deve ser aceito, com o maior lado em 1600 px (teste na Task 4).
4. **COLMAP partindo a cena em vários modelos** (cômodos que não se ligam) — usar o maior, e a razão conta sobre o total de imagens (teste na Task 5).
5. **Um arquivo corrompido no meio de entradas boas** — foto ou vídeo ilegível é pulado e contado no relatório, sem derrubar o job (testes nas Tasks 3 e 8).

```python
"""Códigos de erro do motor (spec §8) e como cada um sai do processo."""

CAPTURE_CODES = frozenset({"CAPTURE_TOO_FEW", "CAPTURE_INSUFFICIENT"})
HOST_CODES = frozenset({"HOST_DOWNLOAD", "HOST_UPLOAD", "HOST_CUDA", "HOST_DISK"})
ENGINE_CODES = frozenset({"ENGINE_ERROR", "MANIFEST_INVALID"})

_EXIT_CODES = {"capture": 10, "host": 20, "engine": 30}


class EngineError(Exception):
    def __init__(self, code: str, detail: str = "") -> None:
        if code not in CAPTURE_CODES | HOST_CODES | ENGINE_CODES:
            raise ValueError(f"código de erro desconhecido: {code}")
        super().__init__(f"{code}: {detail}" if detail else code)
        self.code = code
        self.detail = detail

    @property
    def category(self) -> str:
        if self.code in CAPTURE_CODES:
            return "capture"
        if self.code in HOST_CODES:
            return "host"
        return "engine"

    @property
    def retryable(self) -> bool:
        return self.code in HOST_CODES

    @property
    def exit_code(self) -> int:
        return _EXIT_CODES[self.category]


def classify_command_failure(stderr_tail: str) -> str:
    """Decide se a falha de um comando externo é do host (repetível) ou do motor."""
    text = stderr_tail.lower()
    if "no space left" in text:
        return "HOST_DISK"
    if "cuda" in text or "nvidia" in text:
        return "HOST_CUDA"
    return "ENGINE_ERROR"
```

```python
"""Contrato v1 entre quem dispara o job e a instância de GPU."""

from __future__ import annotations

from dataclasses import dataclass
from pathlib import PurePosixPath
from typing import Any, Literal
from urllib.parse import urlparse

from .errors import EngineError

PRESET_NAMES = ("rapida", "boa", "alta")
MAX_INPUTS = 320
VIDEO_EXTS = frozenset({".mp4", ".mov", ".m4v"})
PHOTO_EXTS = frozenset({".jpg", ".jpeg", ".png", ".heic", ".heif"})
_LOCAL_HOSTS = frozenset({"127.0.0.1", "localhost"})


@dataclass(frozen=True)
class InputFile:
    url: str
    kind: Literal["video", "photo"]
    name: str
    ext: str


@dataclass(frozen=True)
class Outputs:
    splat_url: str
    report_url: str
    viewer_url: str | None


@dataclass(frozen=True)
class Callback:
    url: str
    secret: str


@dataclass(frozen=True)
class Manifest:
    job_id: str
    preset: str
    inputs: tuple[InputFile, ...]
    outputs: Outputs
    callback: Callback | None


def _fail(detail: str) -> EngineError:
    return EngineError("MANIFEST_INVALID", detail)


def _url(value: Any, field: str) -> str:
    if not isinstance(value, str) or not value:
        raise _fail(f"{field} ausente")
    parsed = urlparse(value)
    if parsed.scheme == "https" and parsed.netloc:
        return value
    if parsed.scheme == "http" and parsed.hostname in _LOCAL_HOSTS:
        return value
    raise _fail(f"{field} precisa ser https")


def _input(raw: Any, index: int) -> InputFile:
    if not isinstance(raw, dict):
        raise _fail(f"inputs[{index}] inválido")
    kind = raw.get("kind")
    name = raw.get("name")
    if kind not in ("video", "photo"):
        raise _fail(f"inputs[{index}].kind inválido")
    if not isinstance(name, str) or not name:
        raise _fail(f"inputs[{index}].name ausente")
    ext = PurePosixPath(name).suffix.lower()
    allowed = VIDEO_EXTS if kind == "video" else PHOTO_EXTS
    if ext not in allowed:
        raise _fail(f"inputs[{index}] extensão {ext or '(nenhuma)'} não aceita para {kind}")
    return InputFile(url=_url(raw.get("url"), f"inputs[{index}].url"), kind=kind, name=name, ext=ext)


def parse_manifest(data: object) -> Manifest:
    if not isinstance(data, dict):
        raise _fail("manifesto não é um objeto")
    if data.get("v") != 1:
        raise _fail("versão do manifesto não suportada")
    job_id = data.get("jobId")
    if not isinstance(job_id, str) or not job_id:
        raise _fail("jobId ausente")
    preset = data.get("preset")
    if preset not in PRESET_NAMES:
        raise _fail(f"preset inválido: {preset}")
    raw_inputs = data.get("inputs")
    if not isinstance(raw_inputs, list) or not raw_inputs:
        raise _fail("inputs vazio")
    if len(raw_inputs) > MAX_INPUTS:
        raise _fail(f"mais de {MAX_INPUTS} entradas")
    inputs = tuple(_input(raw, i) for i, raw in enumerate(raw_inputs))

    raw_out = data.get("outputs")
    if not isinstance(raw_out, dict):
        raise _fail("outputs ausente")
    viewer = raw_out.get("viewerUrl")
    outputs = Outputs(
        splat_url=_url(raw_out.get("splatUrl"), "outputs.splatUrl"),
        report_url=_url(raw_out.get("reportUrl"), "outputs.reportUrl"),
        viewer_url=_url(viewer, "outputs.viewerUrl") if viewer is not None else None,
    )

    raw_cb = data.get("callback")
    callback = None
    if raw_cb is not None:
        if not isinstance(raw_cb, dict) or not isinstance(raw_cb.get("secret"), str) or not raw_cb["secret"]:
            raise _fail("callback precisa de url e secret")
        callback = Callback(url=_url(raw_cb.get("url"), "callback.url"), secret=raw_cb["secret"])

    return Manifest(job_id=job_id, preset=preset, inputs=inputs, outputs=outputs, callback=callback)
```

```python
"""Execução de comandos externos (ffmpeg, gsplat, splat-transform) atrás de um protocolo."""

from __future__ import annotations

import subprocess
from collections.abc import Sequence
from pathlib import Path
from typing import Protocol

TAIL_CHARS = 4000


class CommandFailed(Exception):
    def __init__(self, cmd: Sequence[str], returncode: int, stderr_tail: str) -> None:
        super().__init__(f"{cmd[0]} saiu com {returncode}")
        self.cmd = list(cmd)
        self.returncode = returncode
        self.stderr_tail = stderr_tail


class Runner(Protocol):
    def run(self, cmd: Sequence[str], *, cwd: Path | None = None, log: Path | None = None) -> None: ...


class SubprocessRunner:
    def run(self, cmd: Sequence[str], *, cwd: Path | None = None, log: Path | None = None) -> None:
        try:
            proc = subprocess.run(
                list(cmd), cwd=cwd, stdout=subprocess.PIPE, stderr=subprocess.STDOUT, text=True, errors="replace"
            )
        except FileNotFoundError as exc:
            raise CommandFailed(cmd, 127, str(exc)) from exc
        if log is not None:
            log.parent.mkdir(parents=True, exist_ok=True)
            with log.open("a") as fh:
                fh.write(f"$ {' '.join(cmd)}\n{proc.stdout}\n")
        if proc.returncode != 0:
            raise CommandFailed(cmd, proc.returncode, proc.stdout[-TAIL_CHARS:])
```

```python
    registered: int = 0
    gaussians: int = 0
    splat_bytes: int = 0

    gpu: str | None = None
    error: str | None = None

    @contextmanager
    def stage(self, name: str, on_enter: Callable[[str], None] | None = None) -> Iterator[None]:
```

```python
"""Fotos do corretor → JPEGs em pé, no máximo 1600 px, na ordem em que foram tiradas."""

from __future__ import annotations

from collections.abc import Sequence
from dataclasses import dataclass
from pathlib import Path

from PIL import Image, ImageOps, UnidentifiedImageError
from pillow_heif import register_heif_opener

register_heif_opener()

MAX_SIDE = 1600
_EXIF_IFD = 0x8769
_DATETIME_ORIGINAL = 36867


@dataclass(frozen=True)
class NormalizedPhotos:
    paths: list[Path]
    skipped: int


def _capture_time(path: Path) -> str:
    try:
        with Image.open(path) as im:
            value = im.getexif().get_ifd(_EXIF_IFD).get(_DATETIME_ORIGINAL, "")
    except (UnidentifiedImageError, OSError):
        return ""
    return value if isinstance(value, str) else ""


def normalize_photos(sources: Sequence[Path], out_dir: Path, max_side: int = MAX_SIDE) -> NormalizedPhotos:
    out_dir.mkdir(parents=True, exist_ok=True)
    ordered = sorted(sources, key=lambda p: (_capture_time(p), p.name))
    paths: list[Path] = []
    skipped = 0
    for src in ordered:
        try:
            with Image.open(src) as im:
                upright = ImageOps.exif_transpose(im).convert("RGB")
        except (UnidentifiedImageError, OSError):
            skipped += 1
            continue
        upright.thumbnail((max_side, max_side), Image.Resampling.LANCZOS)
        dest = out_dir / f"foto_{len(paths):04d}.jpg"
        upright.save(dest, "JPEG", quality=92)
        paths.append(dest)
    return NormalizedPhotos(paths=paths, skipped=skipped)
```

```python
"""Vídeo → quadros nítidos. Amostra a 4 fps e fica com o mais nítido de cada janela."""

from __future__ import annotations

import shutil
from collections.abc import Sequence
from pathlib import Path

import cv2

from .inputs import MAX_SIDE
from .runner import Runner


def laplacian_variance(path: Path) -> float:
    img = cv2.imread(str(path), cv2.IMREAD_GRAYSCALE)
    if img is None:
        return 0.0
    return float(cv2.Laplacian(img, cv2.CV_64F).var())


def select_sharpest(scores: Sequence[float], window: int, cap: int) -> list[int]:
    if cap <= 0 or not scores:
        return []
    picks = [
        max(range(start, min(start + window, len(scores))), key=lambda i: scores[i])
        for start in range(0, len(scores), window)
    ]
    if len(picks) > cap:
        step = len(picks) / cap
        picks = [picks[int(k * step)] for k in range(cap)]
    return picks


def extract_video_frames(
    video: Path,
    out_dir: Path,
    runner: Runner,
    *,
    cap: int,
    sample_fps: int = 4,
    window: int = 2,
    max_side: int = MAX_SIDE,
) -> list[Path]:
    raw = out_dir.parent / f"_raw_{out_dir.name}"
    raw.mkdir(parents=True, exist_ok=True)
    try:
        scale = (
            f"scale='min({max_side},iw)':'min({max_side},ih)'"
            ":force_original_aspect_ratio=decrease:force_divisible_by=2"
        )
        runner.run([
            "ffmpeg", "-hide_banner", "-loglevel", "error", "-i", str(video),
            "-vf", f"fps={sample_fps},{scale}", "-q:v", "2", str(raw / "f_%05d.jpg"),
        ])
        candidates = sorted(raw.glob("f_*.jpg"))
        picks = select_sharpest([laplacian_variance(p) for p in candidates], window, cap)
        out_dir.mkdir(parents=True, exist_ok=True)
        result = []
        for n, index in enumerate(picks):
            dest = out_dir / f"q_{n:04d}.jpg"
            shutil.move(candidates[index], dest)
            result.append(dest)
        return result
    finally:
        shutil.rmtree(raw, ignore_errors=True)
```

```python
"""Structure-from-motion com pycolmap e o veredito "a captura serve ou não"."""

from __future__ import annotations

from dataclasses import dataclass
from pathlib import Path
from typing import Protocol

from .errors import EngineError

MIN_REGISTERED_RATIO = 0.6
EXHAUSTIVE_MAX_IMAGES = 150
SEQUENTIAL_OVERLAP = 20


@dataclass(frozen=True)
class ModelSummary:
    index: int
    registered: int


class ColmapBackend(Protocol):
    def extract(self, database: Path, images: Path) -> None: ...
    def match(self, database: Path, *, sequential: bool) -> None: ...
    def map(self, database: Path, images: Path, output: Path) -> list[ModelSummary]: ...


class PycolmapBackend:
    """Uma câmera por subpasta (fotos, video0, video1…), modelo OPENCV (lente de celular)."""

    def __init__(self, camera_model: str = "OPENCV") -> None:
        self.camera_model = camera_model

    def extract(self, database: Path, images: Path) -> None:
        import pycolmap

        reader = pycolmap.ImageReaderOptions()
        reader.camera_model = self.camera_model
        pycolmap.extract_features(
            database, images, camera_mode=pycolmap.CameraMode.PER_FOLDER, reader_options=reader
        )

    def match(self, database: Path, *, sequential: bool) -> None:
        import pycolmap

        if sequential:
            pairing = pycolmap.SequentialPairingOptions()
            pairing.overlap = SEQUENTIAL_OVERLAP
            pycolmap.match_sequential(database, pairing_options=pairing)
        else:
            pycolmap.match_exhaustive(database)

    def map(self, database: Path, images: Path, output: Path) -> list[ModelSummary]:
        import pycolmap

        reconstructions = pycolmap.incremental_mapping(database, images, output)
        summaries = []
        for index, rec in reconstructions.items():
            model_dir = output / str(index)
            model_dir.mkdir(parents=True, exist_ok=True)
            rec.write(model_dir)
            summaries.append(ModelSummary(index=index, registered=rec.num_reg_images()))
        return summaries


@dataclass(frozen=True)
class SfmResult:
    registered: int
    total: int
    model_dir: Path

    @property
    def ratio(self) -> float:
        return self.registered / self.total if self.total else 0.0


def run_sfm(images: Path, work: Path, backend: ColmapBackend) -> SfmResult:
    total = len(list(images.rglob("*.jpg")))
    work.mkdir(parents=True, exist_ok=True)
    database = work / "database.db"
    output = work / "sparse_all"
    output.mkdir(parents=True, exist_ok=True)

    backend.extract(database, images)
    backend.match(database, sequential=total > EXHAUSTIVE_MAX_IMAGES)
    models = backend.map(database, images, output)
    if not models:
        raise EngineError("CAPTURE_INSUFFICIENT", f"0/{total} imagens registradas")

    best = max(models, key=lambda m: m.registered)
    result = SfmResult(registered=best.registered, total=total, model_dir=output / str(best.index))
    if result.ratio < MIN_REGISTERED_RATIO:
        raise EngineError("CAPTURE_INSUFFICIENT", f"{best.registered}/{total} imagens registradas")
    return result
```

```python
from __future__ import annotations

import json
import re
from dataclasses import dataclass
from pathlib import Path

from .errors import EngineError
from .runner import Runner


@dataclass(frozen=True)
class Preset:
    name: str
    max_steps: int
    strategy: str


PRESETS = {
    "rapida": Preset("rapida", 7_000, "default"),
    "boa": Preset("boa", 30_000, "default"),
    "alta": Preset("alta", 30_000, "mcmc"),
}

_PLY_STEP = re.compile(r"point_cloud_(\d+)\.ply$")
_VAL_STEP = re.compile(r"val_step(\d+)\.json$")


def train_command(preset: Preset, data_dir: Path, result_dir: Path, *, python: str, trainer: str) -> list[str]:
    steps = str(preset.max_steps)
    return [
        python, trainer, preset.strategy,
        "--data_dir", str(data_dir),
        "--data_factor", "1",
        "--result_dir", str(result_dir),
        "--max_steps", steps,
        "--save_steps", steps,
        "--eval_steps", steps,
        "--ply_steps", steps,
        "--save_ply",
        "--disable_viewer",
    ]


def find_final_ply(result_dir: Path) -> Path:
    found = [(int(m.group(1)), p) for p in (result_dir / "ply").glob("point_cloud_*.ply") if (m := _PLY_STEP.search(p.name))]
    if not found:
        raise EngineError("ENGINE_ERROR", "treino terminou sem PLY")
    return max(found)[1]


def count_gaussians(ply: Path) -> int:
    with ply.open("rb") as fh:
        for raw in fh:
            line = raw.decode("ascii", errors="replace").strip()
            if line.startswith("element vertex "):
                return int(line.split()[-1])
            if line == "end_header":
                break
    raise EngineError("ENGINE_ERROR", "PLY sem element vertex")


def read_psnr(result_dir: Path) -> float | None:
    found = [(int(m.group(1)), p) for p in (result_dir / "stats").glob("val_step*.json") if (m := _VAL_STEP.search(p.name))]
    if not found:
        return None
    value = json.loads(max(found)[1].read_text()).get("psnr")
    return float(value) if value is not None else None


def compress(ply: Path, out_sog: Path, runner: Runner, *, viewer_html: Path | None = None) -> None:
    runner.run(["splat-transform", str(ply), "--filter-nan", str(out_sog)])
    if viewer_html is not None:
        runner.run(["splat-transform", str(out_sog), str(viewer_html)])
```

```python
import json
import threading
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer

import pytest


class FakeStore:
    """Imita o R2 (GET/PUT por caminho) e o endpoint de callback, em 127.0.0.1."""

    def __init__(self):
        self.objects: dict[str, bytes] = {}
        self.events: list[tuple[dict, str]] = []
        self.fail: dict[str, int] = {}
        store = self

        class Handler(BaseHTTPRequestHandler):
            def log_message(self, *args):
                pass

            def _should_fail(self):
                left = store.fail.get(self.path, 0)
                if left > 0:
                    store.fail[self.path] = left - 1
                    self.send_response(500)
                    self.end_headers()
                    return True
                return False

            def do_GET(self):
                if self._should_fail():
                    return
                body = store.objects.get(self.path)
                if body is None:
                    self.send_response(404)
                    self.end_headers()
                    return
                self.send_response(200)
                self.send_header("Content-Length", str(len(body)))
                self.end_headers()
                self.wfile.write(body)

            def do_PUT(self):
                if self._should_fail():
                    return
                length = int(self.headers.get("Content-Length", 0))
                store.objects[self.path] = self.rfile.read(length)
                self.send_response(200)
                self.end_headers()

            def do_POST(self):
                length = int(self.headers.get("Content-Length", 0))
                body = self.rfile.read(length)
                store.events.append((json.loads(body), self.headers.get("X-Visitta-Signature", "")))
                store.objects.setdefault("/_raw_events", b"")
                store.objects["/_raw_events"] += body + b"\n"
                self.send_response(204)
                self.end_headers()

        self.server = ThreadingHTTPServer(("127.0.0.1", 0), Handler)
        self.thread = threading.Thread(target=self.server.serve_forever, daemon=True)
        self.thread.start()

    def url(self, path: str) -> str:
        return f"http://127.0.0.1:{self.server.server_port}{path}"

    def close(self):
        self.server.shutdown()


@pytest.fixture
def store():
    s = FakeStore()
    yield s
    s.close()
```

```python
"""Entrada e saída do host: só URLs assinadas do job e callback assinado com HMAC."""

from __future__ import annotations

import hashlib
import hmac
import json
import shutil
import sys
import threading
import time
import urllib.error
import urllib.request
from collections.abc import Iterator
from contextlib import contextmanager
from datetime import UTC, datetime
from pathlib import Path

from .errors import EngineError
from .manifest import Callback

SIGNATURE_HEADER = "X-Visitta-Signature"
TIMEOUT_SECONDS = 60


def download(url: str, dest: Path, *, attempts: int = 3, backoff: float = 2.0) -> None:
    dest.parent.mkdir(parents=True, exist_ok=True)
    last = ""
    for attempt in range(attempts):
        try:
            with urllib.request.urlopen(url, timeout=TIMEOUT_SECONDS) as resp, dest.open("wb") as fh:
                shutil.copyfileobj(resp, fh, length=1 << 20)
            return
        except (urllib.error.URLError, TimeoutError, ConnectionError) as exc:
            last = str(exc)
            time.sleep(backoff * (attempt + 1))
    raise EngineError("HOST_DOWNLOAD", last)


def upload(path: Path, url: str, content_type: str, *, attempts: int = 3, backoff: float = 2.0) -> None:
    size = path.stat().st_size
    last = ""
    for attempt in range(attempts):
        try:
            with path.open("rb") as fh:
                req = urllib.request.Request(
                    url, data=fh, method="PUT",
                    headers={"Content-Type": content_type, "Content-Length": str(size)},
                )
                with urllib.request.urlopen(req, timeout=TIMEOUT_SECONDS):
                    return
        except (urllib.error.URLError, TimeoutError, ConnectionError) as exc:
            last = str(exc)
            time.sleep(backoff * (attempt + 1))
    raise EngineError("HOST_UPLOAD", last)


def sign(body: bytes, secret: str) -> str:
    return "sha256=" + hmac.new(secret.encode(), body, hashlib.sha256).hexdigest()


class Notifier:
    """Avisa o orquestrador. Falha de callback nunca derruba o job: o prazo do orquestrador cobre."""

    def __init__(self, callback: Callback | None, job_id: str) -> None:
        self.callback = callback
        self.job_id = job_id
        self.stage: str | None = None

    def send(self, type: str, **fields: object) -> None:
        if self.callback is None:
            return
        payload = {"v": 1, "jobId": self.job_id, "type": type, "stage": self.stage,
                   "at": datetime.now(UTC).isoformat(), **fields}
        body = json.dumps(payload, ensure_ascii=False).encode()
        req = urllib.request.Request(
            self.callback.url, data=body, method="POST",
            headers={"Content-Type": "application/json", SIGNATURE_HEADER: sign(body, self.callback.secret)},
        )
        try:
            with urllib.request.urlopen(req, timeout=10):
                pass
        except (urllib.error.URLError, TimeoutError, ConnectionError) as exc:
            print(f"callback {type} falhou: {exc}", file=sys.stderr)

    @contextmanager
    def heartbeat(self, interval: float = 120.0) -> Iterator[None]:
        stop = threading.Event()

        def beat() -> None:
            while not stop.wait(interval):
                self.send("progresso")

        thread = threading.Thread(target=beat, daemon=True)
        thread.start()
        try:
            yield
        finally:
            stop.set()
            thread.join(timeout=5)
```

```python
"""Orquestra os estágios de um job e transforma qualquer falha num código do spec §8."""

from __future__ import annotations

import errno
import shutil
import sys
import traceback
from dataclasses import dataclass
from pathlib import Path

from .errors import EngineError, classify_command_failure
from .frames import extract_video_frames
from .inputs import normalize_photos
from .manifest import Manifest
from .report import Report
from .runner import CommandFailed, Runner
from .sfm import ColmapBackend, run_sfm
from .train import PRESETS, compress, count_gaussians, find_final_ply, read_psnr, train_command
from .transport import Notifier, download, upload

MIN_IMAGES = 40
MAX_IMAGES = 300


@dataclass
class Deps:
    runner: Runner
    colmap: ColmapBackend
    notifier: Notifier
    trainer_python: str
    trainer_script: str
    gpu: str | None = None
    transfer_backoff: float = 2.0


def _set_stage(deps: Deps):
    def enter(name: str) -> None:
        deps.notifier.stage = name
        deps.notifier.send("progresso")
    return enter


def run_pipeline(manifest: Manifest, work: Path, deps: Deps, report: Report) -> None:
    enter = _set_stage(deps)
    data = work / "data"
    images = data / "images"

    with report.stage("baixando", enter):
        local = []
        for i, item in enumerate(manifest.inputs):
            dest = work / "in" / f"{i:03d}{item.ext}"
            download(item.url, dest, backoff=deps.transfer_backoff)
            local.append((item.kind, dest))

    with report.stage("quadros", enter):
        photos = [p for kind, p in local if kind == "photo"]
        videos = [p for kind, p in local if kind == "video"]
        report.photos, report.videos = len(photos), len(videos)
        normalized = normalize_photos(photos, images / "fotos") if photos else None
        if normalized is not None:
            report.skipped_photos = normalized.skipped
        n_photos = len(normalized.paths) if normalized else 0
        remaining = max(0, MAX_IMAGES - n_photos)
        per_video = remaining // len(videos) if videos else 0
        n_frames = 0
        for j, video in enumerate(videos):
            try:
                frames = extract_video_frames(video, images / f"video{j}", deps.runner, cap=per_video)
            except CommandFailed:
                report.skipped_videos += 1
                continue
            n_frames += len(frames)
        report.images_total = n_photos + n_frames
        if report.images_total < MIN_IMAGES:
            raise EngineError("CAPTURE_TOO_FEW", f"{report.images_total} imagens, mínimo {MIN_IMAGES}")

    with report.stage("colmap", enter):
        sfm = run_sfm(images, work / "colmap", deps.colmap)
        report.registered = sfm.registered
        shutil.copytree(sfm.model_dir, data / "sparse" / "0")

    preset = PRESETS[manifest.preset]
    result = work / "result"
    with report.stage("treino", enter):
        deps.runner.run(
            train_command(preset, data, result, python=deps.trainer_python, trainer=deps.trainer_script),
            log=work / "train.log",
        )

    out = work / "out"
    out.mkdir(parents=True, exist_ok=True)
    sog = out / "tour.sog"
    viewer = out / "viewer.html" if manifest.outputs.viewer_url else None
    with report.stage("compressao", enter):
        ply = find_final_ply(result)
        report.gaussians = count_gaussians(ply)
        report.psnr = read_psnr(result)
        compress(ply, sog, deps.runner, viewer_html=viewer)
        report.splat_bytes = sog.stat().st_size

    with report.stage("enviando", enter):
        upload(sog, manifest.outputs.splat_url, "application/octet-stream", backoff=deps.transfer_backoff)
        if viewer is not None and manifest.outputs.viewer_url:
            upload(viewer, manifest.outputs.viewer_url, "text/html; charset=utf-8", backoff=deps.transfer_backoff)


def _as_engine_error(exc: BaseException) -> EngineError:
    if isinstance(exc, EngineError):
        return exc
    if isinstance(exc, CommandFailed):
        return EngineError(classify_command_failure(exc.stderr_tail), exc.stderr_tail[-500:])
    if isinstance(exc, OSError) and exc.errno == errno.ENOSPC:
        return EngineError("HOST_DISK", str(exc))
    return EngineError("ENGINE_ERROR", f"{type(exc).__name__}: {exc}")


def _upload_report(manifest: Manifest, work: Path, report: Report, deps: Deps) -> None:
    path = work / "report.json"
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_bytes(report.to_json())
    try:
        upload(path, manifest.outputs.report_url, "application/json", backoff=deps.transfer_backoff)
    except EngineError as exc:
        print(f"relatório não subiu: {exc}", file=sys.stderr)


def run_job(manifest: Manifest, work: Path, deps: Deps) -> int:
    report = Report(job_id=manifest.job_id, preset=manifest.preset, gpu=deps.gpu)
    deps.notifier.send("iniciou")
    try:
        with deps.notifier.heartbeat():
            run_pipeline(manifest, work, deps, report)
    except Exception as exc:  # noqa: BLE001 — toda falha vira código do spec
        err = _as_engine_error(exc)
        if err.code == "ENGINE_ERROR":
            traceback.print_exc()
        report.error = err.code
        _upload_report(manifest, work, report, deps)
        deps.notifier.send("falhou", code=err.code, retryable=err.retryable, detail=err.detail[-300:])
        print(f"falhou: {err}", file=sys.stderr)
        return err.exit_code
    _upload_report(manifest, work, report, deps)
    deps.notifier.send("concluiu", splatBytes=report.splat_bytes, gaussians=report.gaussians)
    return 0
```

```python
"""CLI da instância: `python -m visitta_engine run --manifest-url URL`."""

from __future__ import annotations

import argparse
import json
import os
import subprocess
import sys
from pathlib import Path

from .errors import EngineError
from .manifest import parse_manifest
from .pipeline import Deps, run_job
from .runner import SubprocessRunner
from .sfm import PycolmapBackend
from .transport import Notifier, download


def _gpu_name() -> str | None:
    try:
        out = subprocess.run(
            ["nvidia-smi", "--query-gpu=name", "--format=csv,noheader"], capture_output=True, text=True, timeout=10
        )
    except (FileNotFoundError, subprocess.TimeoutExpired):
        return None
    return out.stdout.strip().splitlines()[0] if out.returncode == 0 and out.stdout.strip() else None


def _load_manifest(args: argparse.Namespace, work: Path) -> dict:
    if args.manifest_file:
        return json.loads(Path(args.manifest_file).read_text())
    url = args.manifest_url or os.environ.get("VISITTA_MANIFEST_URL")
    if not url:
        raise EngineError("MANIFEST_INVALID", "passe --manifest-url, --manifest-file ou VISITTA_MANIFEST_URL")
    dest = work / "manifest.json"
    download(url, dest, backoff=1.0)
    try:
        return json.loads(dest.read_text())
    except json.JSONDecodeError as exc:
        raise EngineError("MANIFEST_INVALID", f"JSON inválido: {exc}") from exc


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(prog="visitta_engine", description="Motor do Prumo Visitta")
    sub = parser.add_subparsers(dest="command", required=True)
    run = sub.add_parser("run", help="processa um job descrito por um manifesto")
    run.add_argument("--manifest-url")
    run.add_argument("--manifest-file")
    run.add_argument("--workdir", default="/work")
    args = parser.parse_args(argv)

    work = Path(args.workdir)
    work.mkdir(parents=True, exist_ok=True)
    try:
        manifest = parse_manifest(_load_manifest(args, work))
    except EngineError as err:
        print(f"falhou: {err}", file=sys.stderr)
        return err.exit_code

    deps = Deps(
        runner=SubprocessRunner(),
        colmap=PycolmapBackend(),
        notifier=Notifier(manifest.callback, manifest.job_id),
        trainer_python=os.environ.get("VISITTA_TRAINER_PYTHON", "/opt/train/bin/python"),
        trainer_script=os.environ.get("VISITTA_TRAINER_SCRIPT", "/opt/gsplat/examples/simple_trainer.py"),
        gpu=_gpu_name(),
    )
    return run_job(manifest, work, deps)


if __name__ == "__main__":
    sys.exit(main())
```

```python
"""Uso local no spike: sobe uma captura ao R2 e gera o manifesto com URLs assinadas (3h)."""

from __future__ import annotations

import argparse
import json
import os
from collections.abc import Callable
from pathlib import Path

from visitta_engine.manifest import PHOTO_EXTS, VIDEO_EXTS

EXPIRES_SECONDS = 3 * 60 * 60


def build_manifest(
    job_id: str,
    preset: str,
    files: list[Path],
    presign_get: Callable[[str], str],
    presign_put: Callable[[str], str],
    *,
    prefix: str = "spike",
) -> tuple[dict, dict[str, str]]:
    base = f"{prefix}/{job_id}"
    inputs, uploads = [], {}
    for path in sorted(files):
        ext = path.suffix.lower()
        kind = "video" if ext in VIDEO_EXTS else "photo" if ext in PHOTO_EXTS else None
        if kind is None:
            continue
        key = f"{base}/in/{len(inputs):03d}{ext}"
        uploads[key] = str(path)
        inputs.append({"url": presign_get(key), "kind": kind, "name": path.name})
    manifest = {
        "v": 1,
        "jobId": job_id,
        "preset": preset,
        "inputs": inputs,
        "outputs": {
            "splatUrl": presign_put(f"{base}/out/tour.sog"),
            "reportUrl": presign_put(f"{base}/out/report.json"),
            "viewerUrl": presign_put(f"{base}/out/viewer.html"),
        },
        "callback": None,
    }
    return manifest, uploads


def main() -> None:
    import boto3

    parser = argparse.ArgumentParser()
    parser.add_argument("--dir", required=True, type=Path)
    parser.add_argument("--job", required=True)
    parser.add_argument("--preset", default="boa", choices=["rapida", "boa", "alta"])
    parser.add_argument("--bucket", default="visitta-spike")
    args = parser.parse_args()

    s3 = boto3.client(
        "s3",
        endpoint_url=f"https://{os.environ['R2_ACCOUNT_ID']}.r2.cloudflarestorage.com",
        aws_access_key_id=os.environ["R2_ACCESS_KEY_ID"],
        aws_secret_access_key=os.environ["R2_SECRET_ACCESS_KEY"],
        region_name="auto",
    )

    def presign(method: str) -> Callable[[str], str]:
        return lambda key: s3.generate_presigned_url(
            method, Params={"Bucket": args.bucket, "Key": key}, ExpiresIn=EXPIRES_SECONDS
        )

    job_id = f"{args.job}-{args.preset}"
    files = [p for p in args.dir.iterdir() if p.is_file()]
    manifest, uploads = build_manifest(job_id, args.preset, files, presign("get_object"), presign("put_object"))
    for key, local in uploads.items():
        print(f"subindo {local} → {key}")
        s3.upload_file(local, args.bucket, key)
    manifest_key = f"spike/{job_id}/manifest.json"
    s3.put_object(Bucket=args.bucket, Key=manifest_key, Body=json.dumps(manifest).encode())

    print("\nVISITTA_MANIFEST_URL=" + presign("get_object")(manifest_key))
    print("\nSaídas (válidas por 3h depois do job; gere de novo se expirar):")
    for name in ("tour.sog", "viewer.html", "report.json"):
        print(f"  {name}: {presign('get_object')(f'spike/{job_id}/out/{name}')}")


if __name__ == "__main__":
    main()
```
